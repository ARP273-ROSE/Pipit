\section{À quoi sert Pipit}

Débrancher une clé USB ou un disque externe pendant que Windows écrit encore dessus peut
abîmer des fichiers, voire tout le disque. Windows a bien son icône « Retirer le
périphérique en toute sécurité », mais elle est cachée, ne dit pas \emph{quel} programme
bloque quand elle refuse, et n'a pas de raccourci clavier.

Pipit fait la même chose, en mieux rangé :

\begin{itemize}
\item une icône près de l'horloge : un clic montre la liste, un clic sur une ligne éjecte ;
\item un raccourci clavier, actif partout (\touche{Win}+\touche{Alt} par défaut) ;
\item quand Windows refuse, le nom du programme en cause (et des fichiers qu'il garde
  ouverts), un bouton pour le fermer, et en dernier recours l'éjection forcée ;
\item un périphérique éjecté par erreur revient sans le débrancher ;
\item clés, cartes mémoire, SSD, disques durs, téléphones, tablettes, appareils photo et
  lecteurs CD/DVD reconnus, chacun avec son icône (ou la vôtre) ;
\item thème sombre ou clair ;
\item ni le disque de Windows, ni les disques internes ne sont jamais proposés.
\end{itemize}

Pipit est gratuit et le restera : pas de licence, pas de version « Pro », pas de
mise à jour payante.

\section{Installer}

\begin{enumerate}
\item Télécharger \fichier{Pipit-Setup.exe} sur la page
  \url{https://github.com/ARP273-ROSE/Pipit/releases/latest}.
\item Le lancer : l'installation se fait pour votre compte, sans fenêtre
  d'administrateur.
\item Au premier lancement, Pipit pose deux questions : envoyer ou non les rapports
  d'incident, et se lancer ou non avec Windows. Répondez \menu{Oui} à la seconde : c'est
  ce qui le rend toujours disponible quand vous branchez une clé.
\end{enumerate}

\astuce{Si l'icône n'apparaît pas près de l'horloge, cliquez sur la petite flèche
\textbf{\^{}} de la barre des tâches : Windows range là les icônes nouvelles. Faites
glisser celle de Pipit dans la barre pour l'avoir toujours sous la main.}

\section{Retirer un périphérique}\label{sec:retirer}

Cliquez sur l'icône de Pipit (le symbole « éjecter » vert, avec en rouge le nombre de
périphériques branchés ; grisée quand il n'y a rien à retirer) ou appuyez sur
\touche{Win}+\touche{Alt}. Le menu s'ouvre sous la souris :

\capture[0.5]{../capture_menu-fr.png}

Chaque ligne donne l'icône du type de périphérique, la lettre du lecteur, son nom et sa taille. \textbf{Un clic sur la
ligne éjecte le périphérique.} Quand c'est fait, une bulle « Vous pouvez débrancher »
apparaît : vous pouvez retirer le câble.

\begin{itemize}
\item \menu{Tout éjecter} retire tout ce qui est dans la liste, d'un coup.
\item \menu{Plus d'options…} (ou un clic \emph{droit} sur l'icône) ouvre le menu complet.
\end{itemize}

\capture[0.5]{../capture_menu_complet-fr.png}

\begin{itemize}
\item \menu{Forcer l'éjection} : voir section~\ref{sec:forcer}.
\item \menu{Qui utilise ce périphérique ?} liste les programmes qui ont des fichiers
  ouverts dessus, avant même d'essayer d'éjecter.
\item \menu{Ouvrir dans l'Explorateur} ouvre le contenu d'un lecteur.
\item \menu{Réglages…} ouvre la fenêtre décrite section~\ref{sec:reglages}.
\end{itemize}

\subsection{Remonter un périphérique éjecté par erreur}
Un périphérique éjecté mais pas encore débranché apparaît en bas du menu, sous
« Éjectés, encore branchés ». \menu{Remonter …} le rend de nouveau utilisable, sans
toucher au câble. Cela marche aussi pour un périphérique éjecté par Windows ou par un
autre logiciel. Windows n'accepte ce geste qu'avec les droits d'administrateur (fenêtre de confirmation de Windows) : voir
section~\ref{sec:assistant}.

\section{Quand Windows refuse}\label{sec:refus}

Windows refuse d'éjecter tant qu'un programme garde un fichier ouvert sur le
périphérique : un document Word, une photo dans une visionneuse, une vidéo en pause…
Pipit refait d'abord un essai une seconde plus tard (un antivirus qui examine la clé la
lâche souvent tout seul), puis, s'il échoue encore, dit qui est en cause :

\capture[0.6]{../capture_refus-fr.png}

Pipit croise deux sources : le journal de Windows, et la liste des fichiers ouverts par
vos programmes, avec leur chemin.

\begin{itemize}
\item \menu{Montrer …} met la fenêtre du programme au premier plan : enregistrez,
  fermez le document, puis \menu{Réessayer}.
\item \menu{Fermer …} demande poliment au programme de se fermer, exactement comme la
  croix de sa fenêtre : s'il a un document non enregistré, il vous le proposera. Pipit
  réessaie ensuite tout seul.
\item \menu{Chercher partout…} regarde aussi les programmes de Windows et l'antivirus,
  que vos droits ordinaires ne permettent pas de voir.
\item \menu{Forcer…} : voir la section suivante.
\item \menu{Réessayer} relance l'éjection, après que vous avez fermé vous-même ce qu'il
  fallait.
\end{itemize}

Cas particuliers :
\begin{itemize}
\item \textbf{l'Explorateur de fichiers} : une fenêtre est ouverte sur le lecteur, ou le
  volet d'aperçu affiche un de ses fichiers. Fermez cette fenêtre ; Pipit ne ferme jamais
  l'Explorateur, qui emporterait avec lui le bureau et la barre des tâches ;
\item \textbf{un antivirus ou l'indexation de Windows} : patientez quelques secondes et
  réessayez ;
\item \textbf{aucun programme nommé} : Windows ne l'a pas noté. Fermez les documents
  ouverts depuis le périphérique.
\end{itemize}

\section{Forcer l'éjection}\label{sec:forcer}

Quand rien n'y fait (un programme qui ne veut pas lâcher prise, un fichier fantôme),
\menu{Forcer l'éjection} retire quand même le périphérique :
\begin{enumerate}
\item tout ce que Windows garde en mémoire pour ce disque y est d'abord écrit ;
\item le volume est démonté, même avec des fichiers ouverts ;
\item puis le périphérique est éjecté normalement.
\end{enumerate}

\attention{Un document \textbf{non enregistré} sur ce périphérique est perdu, et le
programme qui l'avait ouvert peut afficher une erreur. Pipit le rappelle et demande
confirmation à chaque fois. Ce geste demande les droits d'administrateur
(section~\ref{sec:assistant}).}

\begin{securitebox}
\begin{itemize}[leftmargin=4mm]
\item forcer une éjection sans vous le demander ;
\item fermer de force un programme (« Fermer » demande poliment, comme la croix) ;
\item fermer l'Explorateur, l'antivirus ou un programme de Windows ;
\item proposer le disque de Windows ;
\item installer un pilote ou un service permanent.
\end{itemize}
\end{securitebox}

\section{Lecteurs CD/DVD et images ISO}
\begin{itemize}
\item \textbf{Lecteur CD/DVD}, interne ou externe : un clic \emph{ouvre le tiroir}, comme
  le bouton du lecteur. \menu{Fermer le tiroir} (clic droit) le referme, si le lecteur le
  permet (les lecteurs de portable, à fente ou à ressort, ne savent pas se refermer seuls).
\item \textbf{Image ISO ou disque virtuel VHD} montés (double-clic sur un fichier
  \fichier{.iso}) : un clic les \emph{démonte}. La lettre disparaît, le fichier reste.
\item « Tout éjecter » n'ouvre aucun tiroir et ne démonte aucune image.
\end{itemize}

\section{Lecteurs de cartes à plusieurs fentes}

Un lecteur qui accepte à la fois une carte SD et une carte CF apparaît comme un seul
périphérique avec plusieurs lettres. Windows ne sait éjecter que le lecteur entier :
Pipit vous le rappelle avant de le faire.

\capture[0.6]{../capture_lecteur-fr.png}

Cochez \menu{Ne plus demander} si vous n'utilisez qu'une fente à la fois.

\section{Réglages}\label{sec:reglages}

\menu{Réglages…} dans le menu de l'icône ouvre cette fenêtre. La fermer ne quitte pas
Pipit : l'icône reste près de l'horloge. Pour quitter vraiment : \menu{Quitter Pipit}
dans le menu.

\capture{../capture_reglages-fr.png}

\subsection{Périphériques branchés}
\begin{itemize}
\item \textbf{Icône} : cliquez pour choisir votre propre image (PNG, ICO, SVG, JPG) ou
  revenir à l'icône du type.
\item \textbf{Type} : deviné par Pipit (clé, carte mémoire, SSD, disque dur, téléphone,
  tablette, appareil photo, lecteur CD/DVD…) ; corrigez-le s'il se trompe.
\item \textbf{Nom affiché} : double-cliquez pour donner un nom parlant
  (« Sauvegarde photo » plutôt que « SanDisk Extreme Pro USB Device »). Effacez le nom
  pour revenir à celui du matériel.
\item \textbf{Masquer} : le périphérique n'apparaît plus dans le menu (un disque que vous
  ne débranchez jamais, par exemple). Nom et masquage sont retenus par modèle de
  matériel : Pipit s'en souvient même quand le périphérique est débranché.
\end{itemize}

\begin{itemize}
\item \textbf{Vitesse USB} : la vitesse réelle du port (USB~2.0 — 480~Mbit/s, USB~3 — 5 ou
  10~Gbit/s). Si un périphérique USB~3 tourne en USB~2 (port noir, rallonge, vieux câble),
  Pipit l'écrit et prévient par une bulle à son arrivée : branchez-le sur un port bleu.
\end{itemize}

\subsection{Réglages d'un appareil}
Le bouton \menu{Réglages…} au bout de chaque ligne ouvre les réglages propres à ce
matériel ; Pipit les retient même débranché.

\capture{../capture_appareil-fr.png}
\begin{itemize}
\item \textbf{Lettre fixe} : par exemple toujours \texttt{K:} pour le disque de sauvegarde.
  Windows retient la lettre pour ce volume, comme la Gestion des disques : une seule
  confirmation de Windows suffit. Si la lettre est occupée au branchement, l'appareil en
  reçoit une autre ; Pipit propose alors, par une bulle, de remettre la bonne d'un clic.
\item \textbf{Au branchement, lancer} : un programme ou un script ouvert à chaque arrivée
  de l'appareil (logiciel de sauvegarde, de photos…). Un \texttt{.exe} reçoit la racine du
  lecteur (\texttt{K:\textbackslash}). Il est lancé avec vos droits habituels, jamais en
  administrateur.
\item \textbf{Raccourci qui l'éjecte} : \touche{Ctrl}+\touche{Alt}+\touche{1} à
  \touche{9} ou \touche{Win}+\touche{Alt}+\touche{1} à \touche{9}.
\item \textbf{Couper le courant du port après l'éjection} : le voyant s'éteint, comme sous
  Windows~XP. C'est un réglage du registre de Windows pour ce seul matériel (une
  confirmation de Windows), effectif au branchement suivant. Microsoft l'a documenté pour
  les ports USB~2 ; certains ports USB~3 l'ignorent.
\end{itemize}

\subsection{Raccourcis clavier}
\begin{itemize}
\item \textbf{Ouvrir le menu} : \touche{Win}+\touche{Alt} par défaut (le même que dans
  USB Safely Remove), ou un autre au choix.
\item \textbf{Tout éjecter} : aucun par défaut, pour éviter une éjection par mégarde.
\end{itemize}
Si un autre programme utilise déjà le raccourci choisi, Pipit le signale sous la liste :
choisissez-en un autre.

\subsection{Options}
\begin{itemize}
\item \textbf{Prévenir quand on peut débrancher} : la bulle de confirmation.
\item \textbf{Demander avant d'éjecter un lecteur multicarte} : voir plus haut.
\item \textbf{Montrer aussi les disques internes branchés à chaud} : Windows présente
  souvent les disques SATA internes comme « amovibles ». Pipit les cache pour éviter
  d'éjecter un disque interne par erreur ; cochez seulement si vous avez un tiroir
  ou une baie extractible.
\item \textbf{Montrer téléphones, tablettes et appareils photo}.
\item \textbf{Montrer les lecteurs CD/DVD et les images ISO/VHD}.
\item \textbf{Nombre de périphériques sur l'icône}.
\item \textbf{Rappeler les périphériques oubliés à la fermeture de session} : à l'arrêt du
  PC, Pipit propose de tout éjecter s'il reste quelque chose de branché.
\item \textbf{Lancer Pipit au démarrage de Windows}.
\item \textbf{Langue} : français, anglais, ou celle de Windows.
\item \textbf{Thème} : sombre ou clair, au choix (Windows ne décide pas à votre place).
\end{itemize}

\subsection{Droits d'administrateur}\label{sec:assistant}
Remonter un périphérique, forcer une éjection, « Chercher partout », la lettre fixe et la coupure du
courant demandent les droits
d'administrateur : Windows affiche sa fenêtre de confirmation (UAC) à chaque fois. C'est
voulu. Pipit n'installe ni service ni tâche permanente qui garderait ces droits : aucun
autre programme ne peut donc s'en servir en cachette. La partie administrateur ne reçoit
que le geste et l'identifiant du périphérique ; elle vérifie elle-même qu'il s'agit bien
d'un périphérique externe (ou éjecté encore branché, pour un remontage) et refuse tout le
reste.

\attention{La fenêtre de Windows annonce « Python » (Pipit est écrit dans ce langage), pas
« Pipit ». Elle ne doit apparaître \emph{qu'aussitôt après} un clic de votre part sur
\menu{Remonter}, \menu{Forcer} ou \menu{Chercher partout}. Si elle surgit sans raison,
répondez \menu{Non}.

La version 0.2.0 installait une tâche planifiée « Pipit\textbackslash Assistant » qui s'est
révélée risquée : Pipit la cherche à chaque démarrage et propose de la retirer.}

\section{Mises à jour et rapports d'incident}

Pipit vérifie discrètement, au lancement, s'il existe une nouvelle version, et vous la
propose. Chaque mise à jour est \textbf{signée} : avant de l'installer, Pipit vérifie
qu'elle vient bien de son auteur et qu'elle n'a pas été modifiée en route.

Si Pipit plante ou se fige, et seulement si vous l'avez accepté, un rapport technique
part tout seul (version, système, trace de l'erreur ; ni vos fichiers, ni la liste de vos
périphériques). \menu{Signaler un problème…} permet d'écrire soi-même.

\section{Questions fréquentes}

\textbf{Mon disque externe n'apparaît pas.} S'il est branché en eSATA ou dans une baie
SATA, cochez « Montrer aussi les disques internes branchés à chaud ». S'il est masqué,
décochez \menu{Masquer} dans les réglages.

\textbf{Une souris, un clavier apparaissent-ils ?} Non : ils se débranchent sans précaution.
Téléphones, tablettes et appareils photo, oui (option dans les réglages).

\textbf{Après l'éjection, le disque continue de tourner.} Selon le boîtier, l'alimentation
n'est pas coupée ; il est pourtant bien démonté. Vous pouvez débrancher.

\textbf{Je veux revoir un périphérique éjecté sans le débrancher.} Menu de l'icône →
\menu{Remonter …}. Si Windows refuse quand même, débranchez-le puis rebranchez-le.
