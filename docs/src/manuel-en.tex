\section{What Pipit is for}

Unplugging a USB stick or an external drive while Windows is still writing to it can
damage files, or even the whole drive. Windows does have its “Safely Remove Hardware”
icon, but it is hidden, does not say \emph{which} program is in the way when it
refuses, and has no keyboard shortcut.

Pipit does the same job, better organised:

\begin{itemize}
\item an icon next to the clock: one click shows the list, one click on a line ejects;
\item a keyboard shortcut that works everywhere (\touche{Win}+\touche{Alt} by default);
\item when Windows refuses, the name of the program in the way (and of the files it keeps
  open), a button to close it, and as a last resort a forced ejection;
\item a device ejected by mistake comes back without unplugging it;
\item sticks, memory cards, SSDs, hard drives, phones, tablets, cameras and CD/DVD drives
  are recognised, each with its icon (or yours);
\item dark or light theme;
\item neither the Windows disk nor internal disks are ever offered.
\end{itemize}

Pipit is free and will stay free: no licence key, no “Pro” edition, no paid upgrade.

\section{Installing}

\begin{enumerate}
\item Download \fichier{Pipit-Setup.exe} from
  \url{https://github.com/ARP273-ROSE/Pipit/releases/latest}.
\item Run it: it installs for your account, without an administrator prompt.
\item On first start, Pipit asks two questions: whether to send incident reports, and
  whether to start with Windows. Answer \menu{Yes} to the second: that is what keeps it
  available whenever you plug in a drive.
\end{enumerate}

\astuce{If the icon does not show next to the clock, click the small \textbf{\^{}} arrow
in the taskbar: Windows puts new icons there. Drag Pipit's icon onto the taskbar to keep
it at hand.}

\section{Removing a device}\label{sec:retirer}

Click Pipit's icon (the green “eject” symbol, with the number of connected devices in red;
greyed out when there is nothing to remove) or press \touche{Win}+\touche{Alt}. The menu
opens under the mouse:

\capture[0.5]{../capture_menu-en.png}

Each line shows the icon of the device type, the drive letter, its name and its size. \textbf{One click on the line
ejects the device.} When it is done, a “Safe to remove” balloon appears: you can pull
the cable.

\begin{itemize}
\item \menu{Eject all} removes everything in the list at once.
\item \menu{More options…} (or a \emph{right} click on the icon) opens the full menu.
\end{itemize}

\capture[0.5]{../capture_menu_complet-en.png}

\begin{itemize}
\item \menu{Force ejection}: see section~\ref{sec:forcer}.
\item \menu{Who is using this device?} lists the programs that have files open on it,
  before even trying to eject.
\item \menu{Open in File Explorer} opens a drive's contents.
\item \menu{Settings…} opens the window described in section~\ref{sec:reglages}.
\end{itemize}

\subsection{Bringing back a device ejected by mistake}
A device that was ejected but not yet unplugged appears at the bottom of the menu, under
“Ejected, still plugged in”. \menu{Bring back …} makes it usable again without touching the
cable. This also works for a device ejected by Windows or by another program. Windows only
allows it with administrator rights (Windows confirmation prompt): see section~\ref{sec:assistant}.

\section{When Windows refuses}\label{sec:refus}

Windows refuses to eject while a program keeps a file open on the device: a Word
document, a photo in a viewer, a paused video… Pipit first tries again a second later
(an antivirus scanning the stick often lets go on its own), then, if it still fails,
says who is in the way:

\capture[0.6]{../capture_refus-en.png}

Pipit combines two sources: the Windows log, and the list of files opened by your
programs, with their paths.

\begin{itemize}
\item \menu{Show …} brings the program's window to the front: save, close the document,
  then \menu{Try again}.
\item \menu{Close …} politely asks the program to close, exactly like the cross of its
  window: if it has an unsaved document, it will offer to save it. Pipit then tries
  again on its own.
\item \menu{Search everywhere…} also looks at Windows programs and the antivirus, which
  your ordinary rights cannot see.
\item \menu{Force…}: see the next section.
\item \menu{Try again} retries the ejection once you have closed what was needed.
\end{itemize}

Special cases:
\begin{itemize}
\item \textbf{File Explorer}: a window is open on the drive, or the preview pane shows one
  of its files. Close that window; Pipit never closes File Explorer, which would take the
  desktop and the taskbar with it;
\item \textbf{an antivirus or Windows indexing}: wait a few seconds and try again;
\item \textbf{no program named}: Windows did not record it. Close the documents opened
  from the device.
\end{itemize}

\section{Forcing an ejection}\label{sec:forcer}

When nothing else works (a program that will not let go, a ghost file),
\menu{Force ejection} removes the device anyway:
\begin{enumerate}
\item everything Windows keeps in memory for this disk is first written to it;
\item the volume is unmounted, even with open files;
\item then the device is ejected normally.
\end{enumerate}

\attention{An \textbf{unsaved} document on this device is lost, and the program that had
it open may show an error. Pipit reminds you and asks for confirmation every time. This
requires administrator rights (section~\ref{sec:assistant}).}

\begin{securitebox}
\begin{itemize}[leftmargin=4mm]
\item force an ejection without asking you;
\item kill a program (“Close” asks politely, like the cross);
\item close File Explorer, the antivirus or a Windows program;
\item offer the Windows disk;
\item install a driver or a permanent service.
\end{itemize}
\end{securitebox}

\section{CD/DVD drives and ISO images}
\begin{itemize}
\item \textbf{CD/DVD drive}, internal or external: one click \emph{opens the tray}, like the
  drive's button. \menu{Close the tray} (right click) closes it, if the drive allows it
  (laptop slot or spring-loaded drives cannot close by themselves).
\item \textbf{Mounted ISO image or VHD virtual disk} (double-click on an \fichier{.iso} file):
  one click \emph{unmounts} it. The letter disappears, the file stays.
\item “Eject all” opens no tray and unmounts no image.
\end{itemize}

\section{Multi-slot card readers}

A reader that takes both an SD and a CF card appears as a single device with several
letters. Windows can only eject the whole reader: Pipit reminds you before doing so.

\capture[0.6]{../capture_lecteur-en.png}

Tick \menu{Don't ask again} if you only ever use one slot at a time.

\section{Settings}\label{sec:reglages}

\menu{Settings…} in the icon's menu opens this window. Closing it does not quit Pipit:
the icon stays next to the clock. To really quit: \menu{Quit Pipit} in the menu.

\capture{../capture_reglages-en.png}

\subsection{Connected devices}
\begin{itemize}
\item \textbf{Icon}: click to choose your own image (PNG, ICO, SVG, JPG) or go back to the
  icon of the type.
\item \textbf{Type}: guessed by Pipit (stick, memory card, SSD, hard drive, phone, tablet,
  camera, CD/DVD drive…); correct it if it is wrong.
\item \textbf{Displayed name}: double-click to give a meaningful name (“Photo backup”
  rather than “SanDisk Extreme Pro USB Device”). Clear the name to go back to the
  hardware one.
\item \textbf{Hide}: the device no longer appears in the menu (a drive you never unplug,
  for instance). Names and hiding are remembered per hardware model: Pipit remembers
  them even while the device is unplugged.
\end{itemize}

\subsection{Keyboard shortcuts}
\begin{itemize}
\item \textbf{Open the menu}: \touche{Win}+\touche{Alt} by default (the same as in
  USB Safely Remove), or another of your choice.
\item \textbf{Eject all}: none by default, to avoid an accidental ejection.
\end{itemize}
If another program already uses the chosen shortcut, Pipit says so under the list:
pick another one.

\subsection{Options}
\begin{itemize}
\item \textbf{Notify when it is safe to unplug}: the confirmation balloon.
\item \textbf{Ask before ejecting a multi-card reader}: see above.
\item \textbf{Also show hot-plug internal disks}: Windows often presents internal SATA
  disks as “removable”. Pipit hides them so that an internal disk is not ejected by
  mistake; tick only if you have a removable drive bay.
\item \textbf{Show phones, tablets and cameras}.
\item \textbf{Show CD/DVD drives and ISO/VHD images}.
\item \textbf{Number of devices on the icon}.
\item \textbf{Remind about forgotten devices when signing out}: on shutdown, Pipit offers to
  eject everything if something is still plugged in.
\item \textbf{Start Pipit with Windows}.
\item \textbf{Language}: French, English, or that of Windows.
\item \textbf{Theme}: dark or light, your choice (Windows does not decide for you).
\end{itemize}

\subsection{Administrator rights}\label{sec:assistant}
Bringing a device back, forcing an ejection and “Search everywhere” require administrator
rights: Windows shows its confirmation prompt (UAC) every time. This is deliberate. Pipit
installs no service or permanent task that would keep these rights, so no other program can
use them behind your back. The administrator part only receives the action and the device
identifier; it checks by itself that it really is an external device (or an ejected device
still plugged in, for bringing it back) and refuses everything else.

\attention{The Windows prompt says “Python” (the language Pipit is written in), not “Pipit”.
It must only appear \emph{right after} you click \menu{Bring back}, \menu{Force} or
\menu{Search everywhere}. If it pops up for no reason, answer \menu{No}.

Version 0.2.0 installed a scheduled task “Pipit\textbackslash Assistant” that turned out to
be risky: Pipit looks for it at every start and offers to remove it.}

\section{Updates and incident reports}

On start, Pipit quietly checks whether a new version exists, and offers it. Every update
is \textbf{signed}: before installing it, Pipit checks that it really comes from its
author and was not altered on the way.

If Pipit crashes or freezes, and only if you agreed, a technical report is sent
automatically (version, system, error trace; neither your files nor the list of your
devices). \menu{Report a problem…} lets you write one yourself.

\section{Frequently asked questions}

\textbf{My external drive does not show up.} If it is connected through eSATA or a SATA
bay, tick “Also show hot-plug internal disks”. If it is hidden, untick \menu{Hide} in the
settings.

\textbf{Do mice or keyboards show up?} No: they can be unplugged without precaution. Phones,
tablets and cameras do (option in the settings).

\textbf{After ejection, the drive keeps spinning.} Depending on the enclosure, power is not
cut; it is nonetheless properly unmounted. You can unplug it.

\textbf{I want an ejected device back without unplugging it.} Icon menu →
\menu{Bring back …}. If Windows still refuses, unplug it and plug it back in.
